### Key Algorithm Patterns Explained

#### Two Pointers
The two pointers technique is used when you need to process pairs of elements in an array. It's commonly used for:
- Finding pairs that satisfy a condition
- Searching in sorted arrays
- Reversing arrays
- Detecting cycles

#### Sliding Window
The sliding window technique is used for problems involving subarrays or substrings. It's useful for:
- Finding maximum/minimum in subarrays
- Counting distinct elements in windows
- Finding longest/shortest substrings with conditions

#### Intervals
Interval problems involve working with ranges of time or space. Common operations include:
- Merging overlapping intervals
- Finding gaps between intervals
- Scheduling with time constraints

#### Stack
Stacks are used for problems requiring LIFO (Last In, First Out) order. Common uses:
- Parentheses matching
- Expression evaluation
- Finding next greater/smaller elements
- Backtracking

#### Linked List
Linked list problems test your understanding of pointer manipulation. Key concepts:
- Traversal and modification
- Cycle detection
- Reversal
- Two-pointer techniques (fast/slow)

#### Binary Search
Binary search is used for efficiently searching in sorted data. Applications:
- Finding elements in sorted arrays
- Searching in answer spaces
- Optimization problems

#### Heap/Priority Queue
Heaps are used when you need quick access to min/max elements. Common uses:
- Finding kth largest/smallest elements
- Merge sorted data streams
- Dijkstra's algorithm
- Task scheduling

#### Depth-First Search (DFS)
DFS explores as far as possible along each branch before backtracking. Uses:
- Tree traversal
- Graph exploration
- Path finding
- Connected components

#### Breadth-First Search (BFS)
BFS explores all neighbors at current depth before moving deeper. Uses:
- Shortest path in unweighted graphs
- Level-order traversal
- Connected components
- Flood fill

#### Backtracking
Backtracking is used for problems where you need to explore all possibilities. Applications:
- Combinations and permutations
- Subset generation
- Constraint satisfaction
- N-Queens type problems

#### Dynamic Programming
DP breaks problems into overlapping subproblems. Key patterns:
- Memoization (top-down)
- Tabulation (bottom-up)
- Knapsack problems
- Longest common subsequence
- Edit distance

#### Greedy Algorithms
Greedy makes locally optimal choices at each step. Works when:
- Problem has optimal substructure
- Greedy choice property holds
- Examples: scheduling, minimum spanning tree

#### Trie
Tries are tree-like data structures for strings. Uses:
- Prefix matching
- Autocomplete
- Spell checking
- IP routing

#### Prefix Sum
Prefix sums precompute cumulative sums for range queries. Applications:
- Range sum queries
- Subarray sum problems
- Counting problems
